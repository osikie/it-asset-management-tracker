
# IT Asset Management Tracker

A web-based IT asset inventory dashboard built to demonstrate practical IT Support and IT asset management skills.

## Project Overview

This project simulates an IT asset management system used to track company equipment, monitor asset status, and organize device inventory.

It demonstrates my understanding of IT inventory documentation and basic front-end web development.

## Features

- Dashboard displaying total assets and asset status summaries
- IT equipment inventory table
- Search functionality for devices and asset details
- Asset status indicators: In Use, Available, and Maintenance
- Responsive layout for desktop and mobile devices
- Sample IT asset records for demonstration purposes

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Sample Asset Information

The dashboard includes fictional IT equipment records such as:

- Laptops and desktop computers
- Monitors and printers
- Network and communication devices
- Storage devices and accessories

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No additional dependencies are required.

## Skills Demonstrated

- IT asset inventory management
- IT documentation
- Hardware categorization and status tracking
- Basic JavaScript data filtering
- Front-end development
- Responsive web design

## Disclaimer

This is a portfolio demonstration project. All asset records and employee names are fictional and do not represent actual company data.
